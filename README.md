# 🌾 Smart Crop & Plant Disease Identifier

An end-to-end Machine Learning web application built using TensorFlow/Keras and Flask. The model classifies potato plant leaf diseases from images and provides immediate remediation steps for farmers.

## 📌 Features
- **Deep Learning Classification:** Uses a Convolutional Neural Network (CNN) trained on the PlantVillage dataset.
- **Real-time Inference:** Web interface built with Flask for instant leaf image diagnosis.
- **Actionable Remediation:** Displays immediate agricultural recommendations based on detected disease.

## 🛠️ Tech Stack
- **Language:** Python
- **Frameworks & Libraries:** TensorFlow/Keras, Flask, NumPy, Pillow, SciPy
- **Frontend:** HTML, CSS

## 📊 Dataset & Classes
Trained on Potato leaf datasets featuring 3 primary classes (~95% validation accuracy):
1. Potato Early Blight
2. Potato Late Blight
3. Potato Healthy
